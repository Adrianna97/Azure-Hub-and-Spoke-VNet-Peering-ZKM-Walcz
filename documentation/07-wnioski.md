# ✅ Wnioski

Zastosowanie architektury Hub-and-Spoke z VNet Peeringiem pozwoliło osiągnąć:

- Lepsze bezpieczeństwo (brak ekspozycji usług do Internetu)  
- Skalowalność (łatwe dodawanie kolejnych działów)  
- Centralne zarządzanie politykami i usługami  
- Oszczędność kosztów dzięki redukcji ruchu między lokalizacjami
