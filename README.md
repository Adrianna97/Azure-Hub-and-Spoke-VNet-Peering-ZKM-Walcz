# Azure-Hub-and-Spoke-VNet-Peering-ZKM-Walcz
Implementation of a secure Hub‑and‑Spoke network architecture using Azure VNet Peering for ZKM Wałcz. The project includes centralized Hub services, isolated Spoke networks for each department, NSG‑based traffic control, a jump server for secure access, and private IP routing without exposing resources to the Internet.
